# MrJokeOpa

Osobista strona MrJokeOpa. Statyczne pliki HTML, CSS i JavaScript, bez instalowania zależności.

Repozytorium: `noobxgames5-ops/MrJokeOpa`.

Adres po uruchomieniu GitHub Pages: `https://noobxgames5-ops.github.io/MrJokeOpa/`.

Publikacja: Settings → Pages → Deploy from a branch → main → / (root).

Zmiany treści: `index.html`. Wygląd: `style.css`. Żarty i kopiowanie linku: `script.js`.
